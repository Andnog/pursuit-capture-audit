# Deviations

## D-1. The package's own premise was wrong

It was opened to attempt open routes for records believed blocked. Three of four were never blocked. The
premise held; the prior record it was testing did not.

## D-2. Concessions were written before survivals

The protocol fixed this ordering before reading. It matters here more than usual: GSTAM concedes C04's core
and C05's finding, and a "what survives" written first would have shaped how the concessions were phrased.

## D-3. An HTTP 403 was nearly recorded as a paywall

`curl` on the ACM article returned 403. That is bot protection; the article is open access and the browser
reached it with no credentials. **A refusal by a publisher's edge is not evidence of a subscription wall**,
and the two are easy to confuse in a log.

## D-4. The blocking record is no longer the binding constraint

Riedmiller & Withopf has blocked C04 since 21 September and remains unobtainable. GSTAM, which is readable,
**concedes more than Riedmiller would**. The blocker is still recorded as open, because not reading a source
is not the same as knowing it is subsumed — but it should no longer be treated as the thing standing between
this project and a C04 statement.

## D-5. E03 was read and found irrelevant to the claims

Recorded anyway, at method level, with the one thing it does establish: the lane-constraint motivation is
published prior art. A source that constrains nothing can still constrain the framing.

## D-6. D05 is recommended, not decided

D05 is reserved to the Research lead. The recommendation is negative and the reasoning is recorded; it is not
executed.

## D-7. No resource was consumed

No simulator start, no episode, no optimizer update, no checkpoint load, no TEST access.
