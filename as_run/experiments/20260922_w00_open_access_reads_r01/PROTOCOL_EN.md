# Protocol — reading the records recorded as "blocked on access"

## Move, fixed before executing

Four families were recorded on 21 September as blocked on access. **Attempt the open route for each before
treating any of them as blocked**: preprint servers, publisher open-access full text, and the proxies already
available.

## Acceptance rule, frozen before reading

| Verdict | Condition |
|---|---|
| `REFUTED` | A record implements the conjunction |
| `CONCEDED` | A record implements a component the project claims |
| `NO_CONSTRAINT` | A record cannot bear on the claims |
| `STILL_BLOCKED` | The open route fails and no proxy reaches it |

**A concession is recorded before any statement of what survives it.** A surviving difference written first
is an argument, not a finding.

## Reading-depth rule

A method statement is taken only from the primary text. Descriptions by citing works stay
`SECONDHAND_METHOD_DESCRIPTION_NOT_A_READ`.

## Resource limits

No simulator, no optimizer, no checkpoint, no TEST split.
