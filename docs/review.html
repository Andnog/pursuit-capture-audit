Reproduction guide · Citation ↗

The website is a guide to the evidence, not an independent archival deposit. Use a versioned archive for citation. The source files and PDFs identify the author draft; editorial acceptance is not implied.

Four checks, four different claims.

CheckWhat it establishesWhat it does not establish
Inventory & integrityExpected package directories, unchanged seal files, and matching SHA-256 values. Only omissions listed in the pinned snapshot manifest are permitted.A hash is not a proof of scientific correctness or an external registration timestamp. Public-copy verification is not complete-archive verification.
Independent recomputation13 headline values, including held-out effects and intervals, recomputed from per-episode records.It does not independently recalculate every secondary analysis. Other site values are read from sealed summaries.
Simulator replaySix of six sampled replay records matched the sealed records on 14 October 2026, using SUMO 1.21 and the existing research Python environment.A six-episode check is not a rerun of all studies or a test of installation on another platform.
Historical source recoveryA per-file map identifies which recorded launch-time sources exist in the historical archives.Some launch-time versions are not fully recoverable. Current research code is not guaranteed to be identical to every earlier launch.
git clone https://github.com/Andnog/pursuit-capture-audit.git
cd pursuit-capture-audit
uv sync --frozen
uv run pursuit-audit verify
uv run pursuit-audit recompute
uv run pytest
uv run python tools/build_site_data.py --check
uv run python tools/build_review.py --check

After the companion archive is available, verify its download checksum, extract it over as_run/ as described in the reproduction guide, and run uv run pursuit-audit verify --complete. Until then, this stricter check is expected to fail.

The historical test suite needs a training-state file from the companion archive. The light copy alone is not a complete test environment. Both held-out sets have already been evaluated; repeating their fixed analysis is replication, not a new held-out evaluation.
